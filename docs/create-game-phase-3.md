# เฟส 3 — ตอกลาย และปรับการเพิ่มลาย

## วิธีใช้งาน
1. เปิด `/create` เลือกสีและแบบแผ่น
2. แตะรูปในถาดข้างแผ่นเพื่อเพิ่มลงช่องว่างทันที มือถือถาดอยู่ใต้แผ่นเลื่อนแนวนอนได้ กดลายเดิมซ้ำเพื่อเติมช่องถัดไป
3. จัดครบแล้วกด “เริ่มตอกลาย”
4. แตะชิ้นลายบนแผ่นหรือปุ่มหมายเลขด้านล่าง เพื่อตอกทีละชุด หรือกดตอกที่เหลืออัตโนมัติ (หยุดระหว่างชุดได้)
5. เมื่อตอกครบจะพร้อมสำหรับเฟส 4 อัดกระดาษสี ซึ่งยังไม่ได้เปิดในเฟสนี้

SVG mask ตัดรูจริงออกจากแผ่นฟอยล์ ไม่ระบายสีเลียนแบบโต๊ะ รูใช้ geometry จากต้นฉบับและ transform เดียวกับการจัดวาง มี GSAP ค้อน/เหล็กตอก/สั่นกระดาษ ลด motion เมื่อระบบตั้งค่า reduced motion รองรับปุ่มหมายเลขสำหรับคีย์บอร์ด

เสียง Howler มาจาก WAV จำลองที่สร้างขึ้นเอง 5 เสียง ใน `public/sfx/punch-1.wav` ถึง `punch-5.wav` จึงไม่มีไฟล์ MP3 ว่างหรือ request 404 เปลี่ยนเป็นเสียงจริงภายหลังได้โดยแก้ src ใน `punch-workshop.tsx` เลือกเสียงไม่ซ้ำติดกัน เปิด/ปิดได้ หากเสียงโหลดไม่ได้ยังตอกต่อได้

บันทึกขั้นตอกใน localStorage `ruaphra-punch-v1` ผูกกับรูปแบบงานปัจจุบัน หากแก้การจัดวางจะเริ่มขั้นตอกของงานใหม่ การกลับหน้าจัดวางและกลับเข้าตอกแบบเดิมจะคืนจำนวนที่ตอกแล้ว

ตรวจ Chrome desktop ที่ viewport 360/768/1440: เพิ่มลายด้วยหนึ่งคลิก, ตอกทีละชุด, อัตโนมัติ 6 ชุดรวม 1,878 รู, reload คืนงาน, ไม่ล้นแนวนอน, ไม่มี pageerror ยังไม่ได้ทดสอบเครื่อง Safari/iPad/Android จริงหรือรับรอง 30fps บนอุปกรณ์ระดับกลาง
