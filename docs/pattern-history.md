# เพิ่มข้อมูล “รอยลาย รอยเวลา”

ส่วนนี้แสดงใน `/patterns` และในหน้ารายละเอียดของแต่ละลาย ข้อมูลย้อนหลังเก็บที่ `src/data/pattern-history.json` เป็นรายการ JSON ส่วนภาพปัจจุบันดึงจากคลังจริงโดยอัตโนมัติและแสดงว่าไม่ทราบปี ไม่ใช้ปีเรือหรือวันที่อัปโหลดแทนปีที่ถ่ายภาพ

## เพิ่มบันทึก
1. วางภาพที่อนุญาตให้เผยแพร่ใน `public/photos/pattern-history/` ตั้งชื่อไฟล์อ่านง่าย
2. เพิ่มวัตถุในอาร์เรย์ JSON โดยใช้ `patternSlug` ของลายที่มีในระบบ ค่า `id` ต้องไม่ซ้ำ
3. ระบุปี พ.ศ. ตามหลักฐาน หากไม่ทราบให้เป็น `null` หากประมาณปีให้ `approximate: true` หากเป็นช่วงปีระบุ `yearEnd`
4. วัสดุ เครื่องมือ วิธีทำ และสิ่งที่เปลี่ยนไป หากยังไม่ทราบใช้ `null` ไม่อนุมานจากภาพ กรอกที่มาของคำอธิบายและภาพใน `source`/`credit` ตั้ง `verified: true` เมื่อได้รับการตรวจสอบแล้วเท่านั้น
5. รัน `npm run build` ตรวจข้อมูลและเผยแพร่ตามขั้นตอนปกติของเว็บ ยังไม่มีฟอร์มผู้ดูแลสำหรับข้อมูลชุดนี้

โครงสร้างตัวอย่างสำหรับกรอกข้อมูล (ไม่ใช่ข้อมูลประวัติจริง และไม่ได้แสดงบนเว็บ):

```json
{
  "id": "unique-record-id",
  "patternSlug": "slug-ของลายในระบบ",
  "title": "ชื่อลายและคำบรรยายภาพสั้น ๆ",
  "year": null,
  "yearEnd": null,
  "approximate": false,
  "image": {
    "url": "/photos/pattern-history/ชื่อภาพ.webp",
    "alt": "คำอธิบายสิ่งที่เห็นในภาพ",
    "credit": "เจ้าของภาพ"
  },
  "materials": null,
  "tools": null,
  "technique": null,
  "changes": null,
  "source": "ผู้ให้ข้อมูลหรือเอกสารที่อ้างอิง พร้อมรายละเอียดที่ช่วยตรวจสอบ",
  "location": null,
  "verified": false
}
```

รายการเรียงปีจากเก่าไปใหม่ ส่วนที่ไม่ทราบปีอยู่ท้ายรายการ ภาพเดียวกันและลายเดียวกันที่เพิ่มข้อมูลย้อนหลังแล้วจะไม่ซ้ำกับภาพอัตโนมัติของคลัง บันทึกที่อ้างถึง slug ที่ไม่มีในรายการหรือเป็นข้อมูลสาธิตไม่แสดง

การเทียบภาพเลือกได้สองบันทึก หากเลือกคนละลายจะแจ้งว่าไม่ใช่พัฒนาการของลายเดียวกัน หากมีบันทึกเดียวจะปิดปุ่มเทียบภาพ การซูมใช้ปุ่มขยายภาพและแถบซูม เลื่อนภาพดูรายละเอียดได้ ปิดด้วยปุ่มกากบาทหรือ Escape
