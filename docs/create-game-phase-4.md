# เฟส 4 — อัดดอก

ตอกครบทุกชิ้นแล้วกด “เริ่มอัดดอก” เท่านั้นจึงเข้าขั้นสีได้

- พาเลตอ่าน `data-color` จากลายบนแผ่น รวมสีสำรอง 6 สี
- แตะทีละรู, ลงกลุ่มภายในชิ้นเดียวกัน, ลากระบายด้วย Pointer Events
- รูรับ pointer เฉพาะพื้นที่ path ไม่มี rect รับสีบนฟอยล์ สีวาดด้านหลังฟอยล์ที่ mask เจาะไว้ พร้อมลายผิวกระดาษแบบ multiply
- ขยายแผ่น 1–3 เท่าแล้วเลื่อนดู หรือเลือกรูผ่านรายการเพื่อใช้คีย์บอร์ดและช่วยช่องเล็ก
- ย้อน/ทำซ้ำสี 40 ครั้ง ลากหนึ่งครั้งนับเป็นหนึ่งการแก้ไข
- ชุดสีแบบช่างใช้สีต้นฉบับถ้ามี หากไม่มีสุ่มสีสำรองตามกลุ่ม พร้อมคำอธิบายไม่อ้างว่าเป็นสีดั้งเดิม
- เสร็จสิ้นเมื่อเติมอย่างน้อย 80% ของจำนวนรู ยังไม่ส่งออกหรือแชร์ (เฟส 5)
- JSON สีเก็บใน localStorage `ruaphra-color-v1` ผูกกับ draft ปัจจุบัน ตรวจ key รูและ hex ก่อนคืนงาน

ตรวจ Chrome: เดินเส้นทางวาง→ตอก→อัดดอก, เติมรูผ่านรายการ, ลงกลุ่ม, undo, ชุดสี 1,878 รู, gate 80%, ออกเข้าแล้วคืนสี, viewport 360/768/1440 ไม่มีแนวนอนล้น และไม่มี pageerror ยังไม่ได้รับรองเฟรมเรตบนมือถือจริงหรือ Safari
