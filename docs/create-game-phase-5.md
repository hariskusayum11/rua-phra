# เฟส 5 — ผลงาน ดาวน์โหลด แชร์ และโหมดบูธ

## เล่นครบเส้นทาง
เปิด `/create` หรือปุ่ม “เริ่มสร้างลายของคุณ” ใน `/learn`
เลือกฟอยล์ → วางลาย → ตอกครบ → อัดสี ≥80% → เสร็จสิ้น

หน้าผลงาน:
- ตั้งชื่อเล่นได้ไม่เกิน 40 ตัวอักษร กรองอักขระควบคุมและคำไม่สุภาพเบื้องต้น ไม่ใช่ระบบตรวจภาษาเต็มรูปแบบ
- เลือกแผ่นลาย / เรือพระ / ถุงผ้า / แก้ว เป็น SVG mockup 2D ที่สร้างด้วยโค้ดใน `result-artwork.tsx` ไม่ใช้ภาพสินค้าหรือไฟล์จากบุคคลอื่น
- “เตรียมภาพ PNG” สร้างไฟล์สำหรับมุมมองที่เลือก จากนั้นกดดาวน์โหลดหรือแชร์ เปลี่ยนชื่อ/มุมมองต้องเตรียมภาพใหม่
- PNG กว้าง 1800px ความสูงตามจำนวนเครดิต มีชื่อผู้ทำและเครดิตลายติดภาพ ไม่ครอปทิ้ง
- แชร์ไฟล์ผ่าน Web Share API เมื่อรองรับ มิฉะนั้นดาวน์โหลด PNG ให้ ผู้ใช้ยังต้องเลือกปลายทางและยืนยันเอง ไม่มีการโพสต์อัตโนมัติ
- เก็บไฟล์ JSON ได้ มี version, foil, template, mode, placements, colors, creator และเครดิต ตอนนี้ยังไม่มีปุ่มนำเข้า JSON
- กลับไปแก้สีได้ หรือเริ่มงานใหม่หลังยืนยัน ล้างเฉพาะ storage ของเกม

## การส่งออกและตัวอักษร
Serialize SVG geometry → Image → canvas → PNG Blob รอ `document.fonts.load` และ `document.fonts.ready` ก่อนเขียนข้อความไทยลง canvas เพื่อไม่พึ่งฟอนต์ภายใน SVG image เครดิตหลายบรรทัดตัดตามความกว้างจริง มีการคืน object URL เมื่อเลิกใช้

## โหมดบูธ
เปิด `/create?kiosk=1`
นับ inactivity 90 วินาที แสดงเตือนเมื่อเหลือ 15 วินาที รับ pointer/keyboard/input/wheel เป็นกิจกรรม และรีเซ็ตสถานะเกมกับข้อมูลในเครื่อง ไม่แตะข้อมูลการเข้าสู่ระบบหรือส่วนอื่นของเว็บไซต์

หน้ารวมเครดิต `/credits` แยก 3 แหล่ง ครบ 29 ลาย ยังใช้ placeholder เครดิตตามข้อมูลที่ให้มาเมื่อไม่มีชื่อจริง

## ตรวจสอบ
- Build และ Lint
- Chrome: เล่นครบเส้นทาง, สร้างและดาวน์โหลด PNG 4 มุมมอง (1800×1515 ในงานที่ใช้ลายเดียว), ตรวจภาพชื่อไทยด้วยตา, JSON, แชร์แบบ fallback, 29 เครดิต, ความกว้าง 360/768/1440, clock จำลอง inactivity 91 วินาทีแล้วรีเซ็ต
- สคริปต์ตรวจ: `scripts/reviews/check-create-result.mjs` ใช้ Chrome และเซิร์ฟเวอร์ทดสอบพอร์ต 3106 เป็น read-only ต่อฐานข้อมูล
- ยังไม่ได้ตรวจบน iPhone/iPad Safari หรือ Android จริง การแชร์ native และเฟรมเรต 30fps บนมือถือระดับกลางยังไม่ได้รับรอง
