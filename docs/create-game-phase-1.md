# เกมตอกลาย อัดดอก — เฟส 1

เข้า `/create` หรือกด “สำรวจลายและที่มา” ใน `/learn`

เฟสนี้มีแผ่นงานเปล่า ถาดลาย 29 รายการ แยกหมวด ค้นหา ภาพเส้นร่าง/สีต้นฉบับ และเครดิตทุกลาย รองรับหน้าจอ 360px ขึ้นไปและโหมดมืดตามระบบ ยังไม่มีการวางลาย ตอก ลงสี บันทึกผลงาน หรือส่งออก ซึ่งเป็นเฟส 2–5 ตามแผนที่ผู้ใช้ส่งมา

## แหล่งข้อมูล
- `assets/create-patterns/` เก็บ SVG และ JSON ต้นฉบับจาก lai2svg.zip ไม่แก้ SVG
- `scripts/build-patterns.ts` ตรวจโครงสร้างและรวมลาย รัน `npm run patterns:build`
- `src/data/patterns.json` ชุดข้อมูลรวมสำหรับพัฒนาขั้นต่อไป
- `src/data/create-pattern-catalog.json` รายการย่อสำหรับหน้าเว็บ
- `public/create-patterns/` ภาพตัวอย่างและข้อมูล geometry รายลาย โหลดเมื่อเลือก ไม่ส่ง SVG ทั้งชุดไปกับหน้า

รวม 29 ลาย: ช่างปากพะยูน 4, เอกสาร 9, หนังสือ 16 รวม 1,711 รู

ผู้ใช้ยืนยันในบทสนทนาวันที่ 22 ตุลาคม 2569 ว่าได้รับอนุญาตให้ใช้ชุดเอกสารและหนังสือแล้ว และจะให้เครดิตเพิ่มเติม เครดิตปัจจุบันแสดงตามต้นทาง ไม่เติมชื่อช่างหรือชื่อหนังสือเอง ความหมายเว้นว่างจนมีข้อมูล

แก้ชื่อ/เครดิตเอกสารที่ `assets/create-patterns/lai-from-pdf/patterns.json` ส่วนเครดิตหลักของหนังสือและช่างอยู่ใน `sources` ของสคริปต์ จากนั้นรันตัวสร้างใหม่ SVG ต้นฉบับคงเดิม หมวดเฉพาะบางชื่อถูกรวมเข้าหมวดแม่ในถาด แต่เก็บ `originalCategory` ไว้
