# เฟส 2 — จัดวางลาย

หน้า `/create` เพิ่มโต๊ะจัดวาง เลือกฟอยล์ 5 สี แบบแถบ 6 ช่อง ตาราง 9 ช่อง และสามเหลี่ยม 6 ช่อง เลือกลายในถาดแล้วเพิ่มลงแผ่นหรือแตะช่อง ลากชิ้นที่วางแล้วเพื่อสลับช่อง ในโหมดอิสระลากย้ายตำแหน่งได้ ปรับหมุน ขนาด สะท้อน ลบ ซ้ำทั้งแถว สุ่มครบช่อง และย้อนกลับ/ทำซ้ำได้

บันทึก JSON ที่ localStorage `ruaphra-create-layout-v1` ตรวจข้อมูลก่อนคืนงาน และแจ้งเมื่อพื้นที่เก็บข้อมูลไม่พร้อม ไม่ส่งผลงานไปเซิร์ฟเวอร์

โหมดช่องพร้อมเมื่อทุกช่องมีลาย โหมดอิสระคำนวณพื้นที่รวมของ outline ลง mask 200×120 ต้อง ≥70% พื้นที่ทับกันนับครั้งเดียว ปุ่มเตรียมตอกแสดงสถานะพร้อมสำหรับเฟส 3 ยังไม่ใช่แอนิเมชันตอก

เปลี่ยนแบบหรือเปลี่ยนโหมดเริ่มการจัดวางใหม่ แต่ย้อนกลับได้ จำนวนสูงสุด 60 ชิ้นและประวัติการแก้ไข 40 ครั้ง

ตรวจ Chrome: วางลาย ซ้ำแถว เกณฑ์ครบช่อง ย้อนกลับ รีโหลดคืนงาน ลากอิสระ หน้าจอ 360/768/1440 ไม่มีล้นแนวนอน ยังไม่ได้ทดสอบอุปกรณ์ Safari จริง
