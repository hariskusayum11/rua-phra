# วิธีส่งภาพจริงเข้าเว็บ

ที่นี่คือจุดรับภาพถ่ายจากภาคสนาม วางไฟล์แล้วภาพจะเข้าสู่ระบบด้วยคำสั่งเดียว
ไม่ต้องย่อภาพ ไม่ต้องเปลี่ยนชื่อไฟล์ให้สวย และไม่ต้องแก้โค้ดใด ๆ

---

## 1. วางไฟล์

วางภาพต้นฉบับทั้งหมดไว้ใน:

```
photos/incoming/
```

รับไฟล์ `.jpg` `.jpeg` `.png` `.webp` `.heic` (ถ้ามาจาก iPhone ให้แปลงเป็น JPEG ก่อน)

**ส่งไฟล์ต้นฉบับความละเอียดเต็ม** ระบบจะย่อและแปลงเป็น WebP หลายขนาดให้เอง
ยิ่งต้นฉบับใหญ่ ยิ่งตัดภาพ (crop) ได้อิสระในจอต่างขนาด

ถ้าภาพอยู่ใน Google Drive / Google Photos ให้ดาวน์โหลดแบบ **ขนาดต้นฉบับ**
แล้วลากมาวางในโฟลเดอร์นี้ (ระบบอ่านไฟล์จากเครื่องนี้ ไม่ได้ต่อกับ Drive โดยตรง)

---

## 2. เขียนบริบทที่ภาพบอกไม่ได้

สร้างไฟล์ `photos/incoming/NOTES.txt` แล้วเขียนแบบภาษาคนธรรมดา
บรรทัดละไฟล์ก็ได้ หรือเขียนเป็นย่อหน้าก็ได้ ไม่ต้องจัดรูปแบบ

สิ่งที่ **ต้อง** บอก เพราะดูจากภาพไม่ได้:

| เรื่อง | ตัวอย่าง |
| --- | --- |
| ภาพนี้คือเรือของวัดอะไร ปีอะไร | `IMG_2481 = เรือพระวัดดอนประดู่ พ.ศ. 2568` |
| ชื่อช่างในภาพ | `IMG_2502 = ช่างสมชาย บุญช่วย กำลังตอกลาย` |
| ชื่อลายที่ชาวบ้านเรียก | `IMG_2510 = ลายกระหนก ที่นี่เรียก "ลายกระหนกสามตัว"` |
| ใครเป็นคนถ่าย ถ่ายวันไหน | `ทั้งหมดถ่ายโดย สมศรี ใจดี 12 ต.ค. 2568` |
| **ขออนุญาตแล้วหรือยัง** | `ภาพช่างทุกภาพ ได้รับอนุญาตให้เผยแพร่แล้ว` |

> **เรื่องการขออนุญาตสำคัญมาก**
> ภาพที่เห็นหน้าคนชัด โดยเฉพาะภาพช่างและผู้เรียน ต้องได้รับความยินยอมก่อนเผยแพร่
> ถ้ายังไม่ได้ขอ ให้เขียนว่า `ยังไม่ได้ขออนุญาต` ระบบจะนำเข้าแต่ยังไม่เผยแพร่ให้

สิ่งที่ **ไม่ต้อง** เขียน เพราะผมดูภาพแล้วเขียนให้ได้:
คำบรรยายภาพ (alt text), จุดโฟกัสสำหรับตัดภาพ, ว่าภาพไหนควรไปอยู่ตรงไหนของหน้า

---

## 3. บอกผมว่าวางแล้ว

พิมพ์ในแชทว่า "วางภาพแล้ว" ผมจะ:

1. เปิดดูภาพทุกใบทีละใบ
2. เขียนคำบรรยายภาษาไทยให้ทุกภาพ (จำเป็นสำหรับผู้ใช้โปรแกรมอ่านหน้าจอ)
3. เลือกจุดโฟกัสของแต่ละภาพ เพื่อให้ตอนย่อลงมือถือแล้วยังเห็นสิ่งสำคัญ
4. จับคู่ภาพกับเรือ / ลาย / ช่าง / ขั้นตอน ที่มีอยู่ในฐานข้อมูล
5. ปรับสีและโทนของเว็บให้เข้ากับสีจริงในภาพ
6. สั่งนำเข้า แล้วให้ดูผลก่อนใช้จริง

---

## 4. อยากได้ภาพแบบไหนบ้าง

ถ้ายังไม่ได้ลงพื้นที่ หรือกำลังจะไปถ่ายเพิ่ม นี่คือรายการที่เว็บมีที่ให้ลงพอดี

### เรือพระ (อัตราส่วนแนวนอน 16:9)
- เต็มลำ มุมตรง
- เต็มลำ มุมเฉียง 45 องศา
- ด้านข้าง
- เรือในบริบทจริง มีผู้คน มีสถานที่
- **ภาพเรือช่วงเย็น หรือมีแสงสวย ๆ หนึ่งภาพ** สำหรับหน้าปิดท้าย

### จุดต่าง ๆ บนเรือ (16:9)
เรือหนึ่งลำในเว็บมีจุดให้กดอ่าน **5 จุด** คือ
ยอดเรือ · บุษบกกลางเรือ · หัวเรือ · ท้ายเรือ · แนวลายข้างลำ
👉 **ถ่ายระยะใกล้ให้ครบทั้ง 5 จุด** เพราะใช้ตรง ๆ ในส่วน "อ่านเรือพระ"

### งานกระดาษระยะใกล้ (แนวตั้ง 4:5)
- กระดาษเปล่าเห็นผิวและเนื้อ
- มือช่างจับกระดาษ
- ขณะเขียนแบบ
- **ขณะตอกลาย เห็นเครื่องมือสัมผัสกระดาษ** ← ภาพนี้ขึ้นใหญ่ในหน้าแรก
- ลายที่ตอกเสร็จแล้ว
- ลายที่ติดบนเรือแล้ว

### ลวดลาย (จัตุรัส 1:1 หรือแนวตั้ง 4:5)
ถ่ายลายแต่ละชนิดแบบตรง ๆ เต็มกรอบ ให้เห็นจังหวะซ้ำของลาย
ตอนนี้ในระบบมี 6 ลาย: กระหนกใบเทศ · ดอกพิกุล · จังหวะคลื่น · เกล็ดนาค · กระจังขอบ · เปลวยอด

### ช่าง (แนวตั้ง 4:5)
- **ช่างในพื้นที่ทำงานจริง** ← ภาพนี้ขึ้นใหญ่ในหน้าแรก อย่าถ่ายแบบรูปติดบัตร
- ขณะทำงาน ไม่มองกล้อง
- มองกล้อง
- มือกำลังทำงาน
- เครื่องมือของช่าง
- ช่างกับผู้เรียนอยู่ด้วยกัน

### ขั้นตอนการทำงาน (แนวนอน 3:2)
ถ่ายให้ครบทั้ง 7 ขั้น:
เตรียมวัสดุ → ออกแบบลวดลาย → ทำแม่แบบ → ตอกลาย → อัดดอก → ตกแต่งรายละเอียด → ประดับบนเรือพระ

### ผลงานผู้เรียน (แนวตั้ง 4:5)
ถ่ายผลงานตรง ๆ บนพื้นเรียบ แสงสม่ำเสมอ

---

## 5. ทำไมต้องคุมอัตราส่วน

เว็บจองกรอบภาพไว้ล่วงหน้าตามอัตราส่วนข้างบน เพื่อไม่ให้หน้าเว็บกระตุกตอนภาพโหลด
ถ้าภาพจริงมาคนละอัตราส่วน ระบบจะตัดภาพให้พอดีกรอบ — ซึ่งทำได้ แต่จะเสียขอบภาพไปบ้าง
**ถ่ายเผื่อขอบไว้รอบ ๆ ตัวแบบ** จะปลอดภัยที่สุด

---

## คำสั่งที่เกี่ยวข้อง

```bash
npm run photos:scan
```
ดูว่ามีไฟล์อะไรรออยู่บ้าง ขนาดเท่าไร อัตราส่วนเท่าไร เหมาะกับช่องไหน

```bash
npm run photos:import
```
นำเข้าจริงตาม `photos/manifest.json` (ผมเป็นคนสร้างไฟล์นี้ให้หลังดูภาพแล้ว)
